## Scope

## Decisions

- Planning artifact: `docs/plan/2026-06-08-commercial-product-execution-guide.md`
- Use the agentic execution guide contract so later implementation can continue through a persistent task queue.
- Keep the personal portfolio available, but separate the commercial product surface into public marketing/store routes and authenticated product routes.
- First implementation priority should be monetization infrastructure before adding more standalone features.
