# Add Ludo Game

## Problem
Adding a Ludo game to the Games Hub supporting 3-5 players with polygon-shaped boards (triangle for 3, square for 4, pentagon for 5).

## Solution

### Files Created
- `apps/jayantgoyal/src/components/games/Ludo.tsx` - Main game component with SVG arm-based board
- `apps/jayantgoyal/src/app/(protected)/games/ludo/page.tsx` - Route page

### Files Modified

- `apps/jayantgoyal/src/app/(protected)/games/page.tsx` - Added ludo card theme with amber gradient

### Approach
- **Board redesigned** to match classic Ludo layout (reference image): grid-based square cells in cross/star arms
- Each arm has 3 columns (left track, center home-stretch, right track) x 6 rows deep
- ARM_DEPTH = 6, CELLS_PER_SIDE = 13 (6 + 1 tip + 6 per arm section)
- Colored home bases between arms, colored center polygon divided into player sectors
- Entry cells and star safe cells marked with icons
- Player-to-arm mapping ensures correct clockwise track flow

### Key Decisions
- CELLS_PER_SIDE = 13 (matches standard 4-player Ludo: 52 total track cells)
- HOME_STRETCH_LENGTH = 5 (center column of each arm, depths 1-5)
- playerToArm mapping: player 0→arm 0, player i→arm N-i for correct track flow
- Safe cells at entry (offset 0) and star (offset 8) positions
- Colors: Green, Red, Blue, Yellow, Purple (classic Ludo order)
