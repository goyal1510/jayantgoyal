# Add Ludo Game

## Problem
Adding a Ludo game to the Games Hub supporting 3-5 players with polygon-shaped boards (triangle for 3, square for 4, pentagon for 5).

## Solution

### Files Created
- `apps/jayantgoyal/src/components/games/Ludo.tsx` - Main game component with SVG polygon board
- `apps/jayantgoyal/src/app/(protected)/games/ludo/page.tsx` - Route page

### Files Modified
- `apps/jayantgoyal/src/lib/games/config.ts` - Added "ludo" to GameSlug and GAME_META
- `apps/jayantgoyal/src/app/(protected)/games/page.tsx` - Added ludo card theme with amber gradient

### Approach
- SVG-based polygon board with dynamic shape based on player count
- Track cells along polygon edges (9 per side), home stretches from vertices to center (5 cells)
- Standard Ludo rules: dice rolling, token entry (need 6), captures, safe cells, extra turns
- Follows existing game component patterns (Card + Sheet UI, setup flow)

### Key Decisions
- CELLS_PER_SIDE = 9 for balanced gameplay and visual clarity across all board shapes
- HOME_STRETCH_LENGTH = 5 cells from vertex to center
- Star cells (mid-side) are safe zones; entry cells allow captures
- Extra turns on: rolling 6, capturing opponent, getting token home
- Three consecutive 6s forfeit turn (anti-cheat)
- Dynamic cell sizes based on player count for visual balance
